# RING CLUB

사용자 선택: 3D 브라우저 복싱, 경기 중 1인칭 시점. 기존 저장소는 빈 저장소.

- Three.js + TypeScript + Vite, DOM 메뉴/HUD, Node/Express + Socket.IO.
- 서버 30Hz 고정 스텝: 이동, 사거리, 타격, 체력, 스태미나, 쿨다운 및 경기 종료 판정. 렌더링과 판정 분리.
- 로컬 AI는 같은 시뮬레이션 사용. 온라인은 단일 서버 메모리 로비.
- 초대코드 6자리. 1대1 또는 2~4인 팀. 모두 준비 후 방장 시작.
- 팀별 랜덤 팀장만 30초 동안 출전 순서 변경. 각 순번끼리 90초 대결, KO 또는 남은 체력으로 판정. 팀 승수 동률 시 첫 순번 선수 결정전.
- 연결이 끊기면 30초 대기, 세션 토큰으로 복귀. 시간 초과 시 기권. 서버 재시작 시 로비 초기화.
- 노바·블레이즈·스펙스·볼트 네 명만 제공하며 전신 A포즈 참조를 거쳐 Meshy 모델·리그·여섯 동작으로 연결. 모델이 없는 이전 네 명은 제거. 사진 원본이나 닌텐도 자산을 포함하지 않음.
- 캐릭터 성능은 외모와 독립적으로 파워/속도/회복을 상쇄 배분. 실제 플레이 데이터에 따른 추가 밸런스 튜닝 필요.
- 테스트: 판정/로비 단위 테스트, 실제 서버 복수 브라우저 통합 플레이, 모바일/데스크톱 캡처 및 빌드.

## 초기 밸런스 검증

동일한 클럽 AI 정책으로 시드 1~20, 양쪽 코너를 교대하여 총 240경기를 시뮬레이션했습니다. 현재 네 캐릭터의 속도 조정 후에도 캐릭터당120경기의 승률이 모두 회귀 허용 범위에 들어옵니다. 자동 회귀 기준은 캐릭터별 35~65%이며, 실제 사람의 조작 숙련도와 대전 데이터는 별도 검증이 필요합니다.

## 검토 후 수정

- 30초 이상 끊긴 로비 참가자를 정리하고 방장 권한을 이전합니다.
- 1대1은 무승부도 종료하며, 팀전만 동률 결정전을 진행합니다.
- 출전 순서 편집은 재접속 대기 여부와 무관하게 서버 시각으로 30초 마감합니다.

## 콘솔 UI 및 캐주얼 전투 개편

메인과 로비는 실제 캐릭터가 움직이는 3D 클럽을 배경으로 사용합니다. 왼쪽에서 종목과 대전 모드를 고르고, 대형 캐릭터 미리보기와 하단 초상화 목록, 성능, 스킬 정보를 보여주는 선택 화면을 거칩니다. 로비는 초대코드·팀·준비 상태·시작 동작을 중심으로 구성합니다.

타격 시 시각적인 45ms 히트 스톱, 짧은 카메라 반응, 섬광, 콤보 표시, 저음 효과음을 추가했습니다. 시뮬레이션은 히트 스톱 동안에도 계속되어 온라인 판정에는 영향을 주지 않습니다. Q 스킬은 게이지 100을 소비하며 서버에서 사거리, 가드, 회피, 쿨다운을 판정합니다. 현재 네 캐릭터는 각각 고유 스킬 동작을 사용하며 기본 위력에 캐릭터 파워 배율이 적용됩니다.

최신 네 명은 실제 GLB를 선택창과 전투에서 공유하며 캐릭터별 스킬 동작을 재생합니다. 선택창에서 모델 회전과 스킬 시연이 가능합니다. 필수 안내를 남기고 반복되는 문구를 줄였습니다.

최신 네 모델은 승인된 추가 252크레딧으로 고해상도 재생성·리메시·리깅·애니메이션을 완료했습니다. 얼굴 표면과 눈·코·입 디테일을 개선했으며 사진과 완전히 같은 얼굴은 아닙니다. 모델이 없는 이전 네 명은 사용자의 요청으로 선택창·AI·서버 검증과 자산 목록에서 제거했습니다. 기존 AI 밸런스 테스트는 기본 공격 성능을 검증하며, 사람의 스킬 활용에 따른 밸런스는 추가 플레이 검증이 필요합니다.

## 온라인 공정성과 공개 준비

- 이동은 두 선수의 같은 시작 위치를 사용하고, 피격에 따른 게이지와 가드 비용은 양쪽 공격 처리 후 적용합니다. 동시에 게이지가 100이 되거나 스킬을 교환할 때 좌석 순서에 따라 결과가 바뀌지 않습니다.
- `Room.sync`는 서버가 발급한 접속 세대, 준비한 선수 ID와 로딩 마감을 가집니다. 두 실제 선수만 준비를 알릴 수 있으며, 두 모델 로딩 후 공통 3초 카운트다운을 진행합니다. 60초 로딩 마감은 양쪽에 같은 규칙으로 적용합니다.
- 재접속 및 아직 살아 있는 소켓의 교체 시에도 새 접속 세대를 만들고 두 선수의 조작을 지웁니다. 현재 경기·접속 세대가 아닌 입력은 거부합니다. 브라우저는 온라인 상태에서만 volatile 입력을 전송합니다.
- Render 무료 단일 Node 웹서비스용 `render.yaml`을 사용하며 공개 주소는 `https://ring-club-boxing.onrender.com`입니다. Supabase는 향후 계정·전적 데이터에 적합하며 현재의 상시 Socket.IO 서버를 그대로 배포하는 대상은 아닙니다. 공개 HTTPS 주소에서도 실제 브라우저를 사용해 대전과 재접속을 검사합니다.
- 실제 공개 검사에서 느린 WebGL 초기화가 세션 재연결을 지연시켜 30초 복귀 시간을 넘기는 경우를 재현했습니다. 첫 서버 상태를 받은 뒤 그래픽을 초기화하고 최신 로비·경기 상태를 다시 표시하도록 수정했습니다. 그래픽이 아직 없을 때 준비 완료를 잘못 보내지 않으며, 서버에 연결할 수 없을 때의 로컬 AI 경로도 유지합니다.
- 로비의 `in-room` 스타일이 경기 진입 후에도 남아 링을 23% 불투명도로 표시하던 상태 전환을 수정했습니다. 온라인 경기와 AI 연습에 들어갈 때 로비 상태를 해제하며, 실제 두 브라우저 검사에서 양쪽 링이 원래의 불투명도로 표시되는지 확인합니다.

## 관중과 경기 긴장감

실제 CC0 관중 녹음 세 개를 사용합니다. 낮은 경기장 웅성거림을 반복하고, 실제 피격·연타·스킬·경기 종료에 따라 환호를 재생합니다. 강한 반응은 작은 반응을 대체하며 반복 스냅샷과 반응 대기 시간으로 소리가 겹쳐 쌓이지 않게 합니다. 관중은 전용 음량을 가지며 타격 순간에는 잠깐 작아집니다. 효과음 전체 음소거와 화면 숨김도 따릅니다.

로딩·재접속 대기에서는 관중을 멈추고, 복귀 시 과거 타격을 다시 환호하지 않습니다. 결과 화면에는 마지막 환호를 잠깐 남기되 서버의 반복된 종료 스냅샷이 그 소리를 취소하지 않도록 처리합니다. 내려받는 중 음소거·메뉴 이동·새 경기로 전환된 소리도 나중에 재생되지 않습니다.

기존 시계는 마지막 30초에 주황색, 10초에 붉은색과 짧은 경고 링벨로 바뀝니다. 체력이 낮으면 화면 가장자리에 위험 표시를 더합니다. 추가 패널 없이 기존 HUD를 쓰며 모션 줄이기와 피격 효과 설정을 존중합니다. 경기 판정과 방장 권한은 기존 서버 규칙을 유지합니다.

## 손·글러브와 카메라

1인칭 손과 상대 글러브에 패딩·엄지·손목 스트랩·봉제선·가죽 요철이 있는 공통 메시를 사용합니다. 손가락 관절이 없는 생성 모델은 인스턴스에 복제한 geometry에서 손 관절에 속한 표면만 가리고 글러브를 부착합니다. 원본 GLB, 얼굴, 캐시, 스켈레톤과 실제 애니메이션은 보존하며 복제 geometry는 인스턴스와 함께 해제합니다.

앞손 잽, 뒷손 훅과 캐릭터별 스킬 궤적을 구분합니다. 가드 중에도 중앙 시야를 남기고, 좁은 화면에서는 글러브 비율을 보존해 크기와 위치를 조정합니다. 전완은 손목과 화면 아래를 연결해 어퍼컷에서도 팔 끝이 공중에 끊겨 보이지 않게 합니다. 관전 시 코너와 캐릭터 피부색도 맞춥니다.

카메라는 이동 리듬과 좌우 기울기, 타격 시 짧은 반응을 수 밀리미터·1도 미만 범위에서 보간합니다. 경기·시점 변경 때 이동 이력을 초기화하며 기존 피격 화면 효과 끄기와 모션 줄이기에서는 추가 동작을 끕니다. 조작·충돌·피해 판정에는 적용하지 않습니다.

## 네 캐릭터와 빠른 전투 템포

노바·블레이즈·스펙스·볼트만 선택할 수 있습니다. 이전 캐릭터를 저장한 브라우저는 노바로 전환하고, 서버는 삭제된 ID의 선택을 거부합니다. 캐릭터 선택창은 네 칸이며 모델 목록이 늦게 도착해도 열려 있는 선택창과 다음 화면 이동을 복원합니다. 메인에서 보여 주는 두 캐릭터를 모델 목록 확인 후 내려받고, 메뉴 렌더링은 최대30fps, 선택창이 열린 배경은2fps로 제한합니다. 페이지가 숨겨지면 렌더링을 멈춥니다.

기본 이동은2.0→2.7m/s, 잽 후딜은0.36→0.28초, 훅 후딜은0.85→0.70초로 조정했습니다. 가드하지 않을 때의 스태미나 회복은15→18/초이며 캐릭터 배율, 피해량·사거리·가드 감소율, 회피·스킬 규칙과 경기 시간은 유지합니다. 대각선 이동은 계속 정규화하며 방장·게스트·AI가 같은 시뮬레이션을 사용합니다.

## 복싱 / 주짓수

메인에서 종목을 선택합니다. 초대코드로 참가하면 참가자의 저장된 종목보다 해당 방의 종목이 우선합니다. 1대1·동일 인원 팀전·AI 연습을 두 종목에서 공유하며, 기존 호출은 복싱으로 시작합니다. 복싱의 이동·피해·가드·스킬 규칙은 유지합니다.

주짓수는90초 안에 탭을 받거나 포인트로 승부합니다. W/A/S/D로 접근하고 J로 그립을 쌓은 뒤 K로 테이크다운합니다. 그라운드에서는 J가 상위의 포지션 전진 / 하위의 프레임 만들기, K가 컨트롤·스윕·현재 가능한 서브미션으로 바뀝니다. Space는 방어, Shift는 하위의 포지션 탈출 또는 상위의 전환 방어입니다. 하위 탈출과 스윕에는 준비한 컨트롤과 스태미나가 필요합니다. 상위가 스스로 포지션을 낮췄다 다시 올라가 점수를 반복 획득할 수 없습니다.

테이크다운·스윕2점, 가드 패스3점, 마운트·백 컨트롤4점이며, 암바·트라이앵글·리어네이키드 초크를 지원합니다. K 유지로 압박하고 Space와 Shift로 방어합니다. Q는 캐릭터별 스타일 보너스이며 포지션이나 탭 판정을 강제로 건너뛰지 않습니다. 동일 틱의 양쪽 의도를 먼저 수집해 판정하며 호스트·배열 순서로 동률을 결정하지 않습니다.

기본은1인칭이고 V 또는 화면의 시점 버튼으로 중계 시점으로 바꿀 수 있습니다. 기존 네 모델의 리그에 위치별 두 사람의 관절 목표를 적용하며, 원본 사진·GLB를 다시 생성하거나 수정하지 않습니다. 이는 IK로 구성한 캐주얼 동작이며 실전 주짓수의 모든 자세·규칙을 재현하는 시뮬레이터는 아닙니다. 손은 모델의 실제 맨손 표면·텍스처를 복사하고, 복싱 인스턴스에만 글러브를 붙입니다. 복사한 손 geometry/material은 사용이 끝나면 해제하고 공유 텍스처는 보존합니다.

3D 공간은 복싱 링과 주짓수 매트로 바뀝니다. 테이크다운·스윕에는 매트 낙하음, 그립과 포지션 전환에는 옷 마찰음, 주요 포지션과 서브미션에는 관중 반응을 연결합니다. 주짓수에서는 복싱 타격음과 체력 감소 연출을 사용하지 않습니다. Before the Bell은 메인·로비·팀 출전 순서 대기에서 이어 재생하고 경기 시작 시 멈춥니다. 음악 음소거와 화면 숨김 설정을 따르며 기존 음원·라이선스를 유지합니다.

## 모바일 화면과 입력

모바일의 문서 스크롤을 고정하고 메뉴·로비·대화창 안쪽에서만 필요한 내용을 스크롤합니다. `visualViewport` 높이·위치를 따라 키보드, 주소 표시줄, 기기 회전에 맞추며 노치와 하단 안전 영역을 반영합니다. 16px 이상의 입력 글자로 Safari의 입력창 포커스 자동 확대를 방지하고, 경기장·터치 버튼에서는 끌기·핀치·이중 탭에 의한 화면 이동을 막습니다. 메뉴에서 사용자가 의도한 확대는 유지합니다.

각 손가락과 키보드가 누른 입력을 따로 저장합니다. 이동 손가락을 떼어도 다른 손가락의 그립·공격이 유지되며, 포인터 취소·캡처 해제·화면 숨김·연결 종료에서는 해당 입력을 해제합니다. 작은 가로 화면에서는 HUD를 줄이고 로비의 준비·시작 버튼은 내부 스크롤 안에서 접근할 수 있습니다. Chromium 터치 에뮬레이션으로 검사하며, 실제 iOS의 운영체제 키보드·주소 표시줄은 실기기 확인 범위입니다.

짧은 주짓수 화면의 시점 버튼은 하단 중앙에 배치해 자세 안내·점수·스태미나·나가기 버튼과 겹치지 않게 합니다. 높이360px 이하에서는 보조 설명을 줄이고 현재 자세와 동작 이름을 유지합니다. 320px 폭부터568×320 가로 화면까지 겹침과 화면 경계를 검사합니다.
