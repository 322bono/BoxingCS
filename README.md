# RING CLUB ↗

친구끼리 즐기는 **3D 1인칭 브라우저 복싱 게임**. TypeScript / Three.js / Vite / Socket.IO / Express.

## 실행

Node.js 22.12 이상(현재 환경: 24.22), npm이 필요합니다.

```sh
npm ci --cache /tmp/boxing-npm-cache
npm run dev
```

하나의 Node 서버가 프런트엔드와 소켓 대전을 함께 제공합니다. 기본 포트는 `3000`이고 `PORT`로 변경할 수 있습니다. 같은 서버에 접속한 서로 다른 브라우저에서 초대코드로 참가합니다. AI 연습은 서버 연결이 없어도 이미 로드된 페이지에서 가능합니다.

```sh
npm test                 # 판정 및 로비 단위 테스트
npm run build            # TypeScript 검사 + 프로덕션 번들
npm run test:e2e         # 시스템 Chromium으로 실제 브라우저/네트워크 테스트
npm start                # 빌드된 dist를 서비스
```

브라우저 테스트 기본 실행 파일은 `/usr/bin/chromium`입니다. 다른 환경은 `CHROMIUM_PATH`를 지정하세요. 테스트 서버는 포트 3000을 사용합니다. 실행 중인 서버가 있으면 재사용합니다.

## 플레이

- **1 vs 1**: 닉네임 → 로비 만들기 → 6자리 코드 공유 → 두 사람 모두 준비 → 방장 시작.
- **팀 vs 팀**: 2:2 / 3:3 / 4:4 선택. 로비에서 팀 이동 가능. 두 팀 모두 같은 인원으로 준비해야 합니다. 시작 시 팀별 팀장 랜덤 배정. **팀장만 30초 동안 출전 순서 변경** 가능. 각 순번끼리 대결하며 대기 선수는 1인칭 관전 시점을 바꿀 수 있습니다.
- **팀 승리**: 선수별 90초 단판, KO 또는 남은 체력 판정. 더 많은 승수를 얻은 팀 승리. 팀 점수가 같으면 첫 번째 선수끼리 결정전. 결정전도 무승부이면 재대결합니다.
- **AI 연습**: 루키 / 클럽 / 프로 난이도. 파이터마다 같은 기본 체력 100, 파워·속도·스태미나 회복의 상쇄되는 차이.
- **재접속**: 같은 탭을 새로고침하면 로비/경기로 복귀. 연결이 끊긴 동안 경기를 멈추고 30초를 기다립니다. 이후 기권 처리. 다른 탭은 다른 세션입니다.
- **재대결**: 경기 종료 후 방장이 로비를 다시 열고 모두 준비하여 시작.

### 온라인 공정성

방장은 로비 시작·재대결만 관리합니다. 이동·사거리·피해·가드·스태미나·스킬·경기 시계는 중앙 서버에서 동일한 30Hz 규칙으로 계산합니다. 양 선수의 이동은 같은 시작 위치를 기준으로 계산하고, 맞아서 얻은 게이지는 양쪽 공격을 처리한 뒤 적용합니다. 먼저 참가한 자리의 처리 순서가 이익을 주지 않습니다.

경기는 두 선수의 실제 3D 로딩이 끝난 뒤 공통 3초 카운트다운으로 시작합니다. 재접속과 기존 연결 교체도 두 선수의 준비를 다시 확인합니다. 로딩이 60초를 넘으면 준비되지 않은 쪽이 기권하며, 양쪽 모두 준비되지 않으면 무승부입니다. 연결 종료의 30초 복귀 제한은 별도로 적용합니다.

조작은 현재 경기·접속 세대에만 유효하며, 끊긴 동안 보관했다가 재생하지 않습니다. 클라이언트가 전송한 체력·피해량·진행 시간은 사용하지 않습니다. 실제 인터넷 거리·지연과 기기의 화면 표시 차이는 남지만, 방장 컴퓨터에서 경기를 판정하거나 방장에게 별도 성능을 주지 않습니다.

### 기본 조작

| 입력          | 행동                     |
| ------------- | ------------------------ |
| W / S         | 전진 / 후진              |
| A / D         | 좌우 스텝                |
| J 또는 좌클릭 | 빠르고 긴 잽             |
| K 또는 우클릭 | 짧고 강한 훅             |
| Space         | 가드, 피해 75% 감소      |
| Shift         | 순간 회피, 스태미나 소모 |
| Q             | 게이지 100에서 고유 스킬 |
| Esc           | 누른 입력 해제 / 창 닫기 |

상대를 자동으로 바라보는 1인칭 시점입니다. 카메라를 마우스로 회전하지 않습니다. 모바일 터치 조작을 지원합니다. 설정에서 키 변경·배경음악·효과음·피격 효과를 변경할 수 있으며 브라우저에 저장됩니다.

### 음악과 효과음

메인 화면에서 업로드한 **Before the Bell**을 반복 재생합니다. 브라우저의 자동 재생 정책에 따라 첫 클릭이나 키 입력 후 음악이 시작됩니다. 로비·경기·결과 화면에서는 음악을 멈추고 메인으로 돌아오면 이어서 재생합니다. 메인 오른쪽 스피커 버튼과 설정에서 배경음악을 끌 수 있고, 효과음은 별도로 켜고 끕니다. 탭을 숨기면 소리가 멈춥니다.

타격 강도별 펀치, 가드, 스윙·회피, 발소리, KO와 시작·종료 링벨에 샘플 효과음을 사용합니다. 피격 판정과 스킬 발동에 맞추며 재접속 시 이전 타격음을 다시 재생하지 않습니다. CC0 원본의 출처와 가공 내역은 [오디오 자산 기록](docs/audio-assets.json)과 `public/audio/CREDITS.txt`에 있습니다. 음악 원본 파일은 변경하지 않았습니다.

## 구조

- `shared/game.ts`: 렌더러와 분리된 대전 규칙 및 AI. 온라인에서는 서버만 판정.
- `server/rooms.ts`: 초대·준비·팀장·순서·팀전·재접속 상태.
- `server/index.ts`: 30Hz 서버 시뮬레이션, 입력 검증, Socket.IO, 개발/프로덕션 서버.
- `src/world.ts`: 3D 링, 캐릭터, 1인칭 글러브와 타격 효과.
- `src/assets/`: 생성된 GLB 로딩, 스켈레톤 복제, 행동별 애니메이션, 선택창 3D 미리보기.
- `src/audio/`: 배경음악·샘플 효과음 재생과 대전 상태 변화에 따른 중복 없는 소리 판정.
- `src/main.ts`, `src/style.css`: 한국어 메뉴·로비·HUD·설정.
- `public/characters/models`: 최신 네 인물의 전신 GLB, 리그·동작, 모델에서 렌더링한 초상화. 기존 네 명은 임시 모델입니다. 원본 사진 및 닌텐도 자산은 포함하지 않습니다.

## 인터넷 서비스 배포

공개 게임 주소: **https://ring-club-boxing.onrender.com**. 친구들과 같은 주소에 접속한 뒤 초대코드로 참가합니다. 웹페이지와 실제 Socket.IO 대전 서버를 하나의 Node 웹서비스에서 제공합니다. 정적 호스팅만으로는 온라인 대전이 동작하지 않습니다.

1. Node 서버에서 `npm ci`, `npm run build`, `npm start` 실행.
2. HTTPS 도메인과 WebSocket 업그레이드를 지원하는 리버스 프록시를 연결.
3. 친구들에게 동일한 도메인을 공유하고, 로비의 초대코드로 참가.

현재 로비/경기 상태는 **단일 서버 메모리**에 있습니다. 서버를 재시작하면 초기화되며 여러 서버 인스턴스 간 공유는 지원하지 않습니다. 계정·랭킹·영구 기록은 구현하지 않았습니다. 공개 대규모 서비스 전에는 지속 저장, 공유 세션 저장소, 운영 모니터링 및 부하 테스트가 필요합니다. 캐릭터 밸런스는 초기 수치를 적용했으며 실제 사람들의 대전 데이터로 추가 조정해야 합니다.

Render 무료 웹서비스 설정은 `render.yaml`, 계정 연결과 실제 공개 후 검사 절차는 [웹사이트 공개 안내](docs/public-deployment.md)에 있습니다. Supabase는 계정·전적 저장에 사용할 수 있으며 현재의 지속 실행 Node 대전 서버는 별도 웹서비스에서 운영합니다.

건강 확인: `GET /api/health` → `{"status":"ok","game":"ring-club","rooms":0}` (로비 수는 달라집니다).

## 화면 및 전투 개편

메인은 화면 전체를 채우는 대전·트레이닝·팀 배틀·파이터·온라인 패널로 구성했습니다. 모드 선택 후 대형 캐릭터 미리보기와 초상화 목록이 있는 선택 화면을 거칩니다. Q 스킬은 공격/피격 및 시간 경과로 충전되며 가드 관통·장거리·근거리 고위력·균형형으로 구분됩니다. 타격 섬광·짧은 시각 히트 스톱·카메라 반응·콤보·스킬 배너·효과음을 지원합니다. 시각 효과는 서버 판정 시간을 멈추지 않습니다.

최신 네 인물은 사진을 참고해 만든 전신 A포즈 이미지를 Meshy에 한 명씩 제출하여 모델·리깅·캐릭터별 동작을 생성했습니다. 선택창에서 실제 3D 모델을 회전하고 스킬을 시연할 수 있습니다. UI는 이름·성능·스킬과 필요한 조작 안내를 중심으로 정리했습니다.

최신 네 모델은 승인된 고해상도 재생성으로 얼굴 표면과 디테일을 개선했습니다. 사진과 완전히 같은 얼굴은 아니며 처음 보내신 네 명은 로컬 원본 사진이 없어 임시 모델을 유지합니다. 현재 품질과 실제 작업·비용은 [캐릭터 작업 상태](docs/meshy-character-pipeline.md)에 기록했습니다.
